# Etusivu (`/index.html`, `page-front.js`)
1. Pääotsikko yhtenä kokonaisena virkkeenä: riittääkö tulorahoitus investointeihin (vuosikate/poistot ja rahavirta ilman luovutustuloja kolmelta vuodelta).
2. Ingressi: kunnan sija talouden vahvuuden pisteytyksessä ja kokoluokan kolme vahvinta.
3. Kuusi avainlukua `<kpi-tile>`-komponentteina: vuosikate/poistot, rahavirta ilman luovutustuloja, lainakanta, toimintakulut, efektiivinen veroaste ja kiinteistövero. Ero kokoluokan keskiarvoon on vihreä (parempi) tai punainen (heikompi).
4. Verrokkivalitsin.
5. Neljä nostoa, yksi kustakin näkökulmasta, ja jokaisessa pieni kuvaaja. Toimenpiteistä näytetään viiden osa-alueen tärkein nosto.
